# Sales Data Analysis
## Project Description

This project analyzes sales data using Python, Pandas, and Matplotlib.
The analysis focuses on sales, profit, quantity, products, categories,
cities, regions, payment methods, discounts, and monthly performance.
## Technologies Used

- Python
- Pandas
- Matplotlib
- VS Code
- Git & GitHub
## Dataset Information

- Total Records: 1000
- Total Columns: 12
- Year: 2024
- Dataset contains sales, profit, quantity, product, category,
  city, region, discount, and payment method information.
  ## Analysis Performed

- Data inspection
- Data cleaning
- Missing value checking
- Duplicate value checking
- Data type checking
- Product-wise sales and profit analysis
- Category-wise sales and profit analysis
- City-wise sales and profit analysis
- Region-wise sales and profit analysis
- Payment method-wise analysis
- Monthly sales and profit analysis
- Quantity analysis
- Discount analysis
- Top 5 analysis
- Overall business performance analysis
